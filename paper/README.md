# Paper draft

First draft of the SAXS-TT neural-field paper, targeting Acta Cryst. A / J. Synchrotron
Radiation.

```
paper.tex              manuscript
paper.bib              references (all verified against Crossref/arXiv — see note below)
figures/make_figures.py   figure generator (spec-driven)
figures/make_all.sh       regenerates every figure in the paper
figures/*.pdf             generated figures
```

## Building

```bash
cd /myhome/smartt/paper
pdflatex paper && bibtex paper && pdflatex paper && pdflatex paper
```

## Regenerating figures

Every figure is one `--fig` spec, so the figure list grows or shrinks without touching
code. To regenerate all of them as they appear in the paper:

```bash
bash figures/make_all.sh
```

To retune one figure — the slice indices and the reciprocal-space direction are the knobs
you are most likely to want:

```bash
cd figures
python make_figures.py --fig "dataset=zenodo:dc_type=main:k=0:x=30:y=33:z=40:diff=1:name=fig_trabecular_bone_wedge"
```

(`dataset=zenodo` is the dataset registry key, unchanged in code — it just names
where the raw data is hosted. The paper itself never uses that name; it calls this
dataset `trabecular-bone` everywhere a human reads the label, so figure titles and
filenames use `trabecular_bone`/`trabecular-bone` instead.)

Spec keys: `dataset`, `dc_type`, `ell_max`, `holdout`, `k` (RSM direction), `x`/`y`/`z`
(slice indices), `planes` (subset of `xy,xz,yz`), `methods`, `name`, `cmap`, `diff`.

To choose `k`, list the directions ranked by how badly the missing wedge hits them:

```bash
python make_figures.py --list-directions dataset=zenodo
```

With the standard 45-degree tilt limit, `k=0` is the worst case (180-degree missing arc)
and `k=2` is fully measured — the contrast pair used in the paper.

## Numbers

Every value in the results tables comes from `../PAPER_RESULTS.md`, which is generated by
the `paper_gather_*_ablation.py` scripts in `../scripts/` reading directly from the
reconstruction cache (these scripts still use the `zenodo` dataset registry key — see the
naming note above). The paper presents the **unregularised** NAF variant as the default;
the `trabecular-bone` cross-mount table additionally shows the regularised variant, because
that is the one dataset where the smoothness penalty changes the margin (though not the
winner).

**trabecular-bone has no independent ground truth**, unlike the other five datasets. The
obvious candidate — reconstructing the combined (near-full-coverage) two-mount data — is
itself a `mumott GK` output, so scoring reconstruction methods against it is circular for
that method. The paper therefore reports trabecular-bone only via the cross-mount test
(train on one mount, predict the other's real projections), which needs no reconstructed
reference at all. `PAPER_RESULTS.md` still lists the GT-based numbers for
reference/debugging, but they are deliberately excluded from the manuscript's results
tables. The qualitative figures (`fig_trabecular_bone_wedge`, `fig_trabecular_bone_covered`)
still show the combined `mumott GK` reconstruction as a visual anchor, but the column is
labelled `Combined (GK), not GT` — see `_GT_DISPLAY_OVERRIDE` in `make_figures.py` if you
need to change that wording.
